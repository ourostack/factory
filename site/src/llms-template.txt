# The factory

> The factory is the public measurement store for Desk, a plugin that gives coding agents a durable desk of tracks and tasks. It measures agentic work the way Lean measures a factory floor: where each task's time went, which part added value, and which part was waste. It names no person, no machine and no date. This file indexes the data behind every view, for agents.

Site: https://ourostack.github.io/factory/
Source and raw data: https://github.com/ourostack/factory (the `reports` branch holds the built reports)

## How to walk it

The site walks the four steps Lean uses to see waste, in this order. Read the data in the same order.

1. Follow a task (`#/task/<job>`; `#/` opens the task that finished last): one real task end to end, and where its time went.
2. Compare tasks (`#/compare`): every task side by side on one scale.
3. Rank causes (`#/causes`): causes of waste ranked by the time they cost.
4. Act (`#/act`): the problems taken on, each with its countermeasure.

Reference pages: `#/why` (why Lean, the eight wastes and a glossary), `#/about` (how the data gets here and the privacy rules), `#/store` (everything else the store measures).

## Reading the numbers

Every number is an object `{ state, value?, reasons }`. `measured` is the whole figure. `partial` is part of it, and `bound` says whether the true figure is higher (`lower`) or lower (`upper`) or not known. `unavailable` means not measured: it has no value and is never zero. A rollup also carries `n` of `N` and what it counts. Tasks are ordered by `finish_order`, a position, never a date: the order in which each task's first waste labels landed in the store, then open tasks by their first facts file.
